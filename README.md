# espmatter studio

Configure, build and flash ESP32 firmware for Matter hubs and devices from the browser.

## Run

```sh
pnpm install
pnpm dev                     # http://localhost:5173
```

Or with Docker: `docker compose up -d --build` (http://localhost:3000).

The first account you create is the admin. Under **Admin**, add a build runner and set the public URL that devices use to reach the app.
